# Habit Master Pro - Premium Productivity Dashboard

A world-class habit tracking application with a premium, modern design inspired by top SaaS products like Notion, Linear, and Stripe Dashboard.

## 🎨 Features

### Core Dashboard
- **Premium Dark Theme** - Beautiful dark mode with subtle gradients and glass effects
- **Responsive Design** - Perfect on Desktop, Tablet, and Mobile
- **Smooth Animations** - Fade, slide, scale, and progress animations throughout
- **Professional Typography** - Inter font family with JetBrains Mono for numbers

### Habit Tracking
- **Weekly View** - Interactive 7-day habit grid with progress indicators
- **Monthly View** - Comprehensive month-long tracking table
- **Habit Icons** - Emoji icons for each habit type (⏰🏋️📚💻📝🚰🥗🧘🚶📱😴📖🙏🎯)
- **Sticky Columns** - First column stays visible while scrolling
- **Weekend Highlighting** - Subtle color differentiation for weekends
- **Today Highlight** - Current day prominently marked
- **Instant Updates** - Real-time checkbox toggling with smooth animations

### Analytics & Statistics
- **Overall Completion** - Monthly progress percentage with animated ring chart
- **Current Streak** - Track consecutive days of completion
- **Best Streak** - Historical best performance
- **Total Completed** - Total habits completed this month
- **Success Rate** - Weekly average success percentage
- **Daily Progress Chart** - Bar chart showing daily completion rates
- **Top Habits** - Ranked list of best-performing habits with progress bars

### Additional Features
- **Mood Tracker** - Emoji-based mood tracking with trend visualization
- **Sleep Tracker** - Sleep hours tracking with weekly trends
- **Goal Tracker** - Active goals with progress and deadlines
- **Monthly Calendar** - Visual calendar with completion indicators
- **Local Storage** - All data persists locally in your browser
- **Export/Import** - Data management capabilities

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- No build process required - runs directly in browser

### Installation

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Start tracking your habits!

## 🎯 Usage

### Adding Habits
1. Click the "Add Habit" button in the top right
2. Enter habit name
3. Select an icon from the emoji picker
4. Set monthly goal (number of days)
5. Choose a category
6. Click "Save Habit"

### Tracking Habits
- **Weekly View**: Click checkboxes in the weekly grid
- **Monthly View**: Click checkboxes in the monthly table
- Changes save automatically

### Navigation
- Use the sidebar to navigate between sections
- Use date selectors to change month/year
- Use arrow buttons to navigate weeks

### Analytics
- View real-time statistics in the top cards
- Check the progress ring for monthly completion
- Review top habits for performance insights
- Track mood and sleep patterns
